# Student Team Mongolia (STM) — цагийн ажлын систем

tsagiin-ajil-ийн backend (Google Sheet + Apps Script, GitHub Pages) дээр STM прототипийн логик, UI-г бүрэн ажилладаг болгосон хувилбар. Үнэгүй ажиллана.

| Хуудас | Хэн | Юу хийдэг |
|---|---|---|
| `index.html` | Оюутан | Бүртгүүлэх, нэвтрэх, зар харах, өдрөө сонгож бүртгүүлэх, сонгогдвол баталгаажуулах, QR/кодоор ирц, цалин, сургалт, тест, мессеж, SOS |
| `company.html` | Захиалагч | Гэрээ цахимаар зурах, өнөөдрийн баг, ирцийн QR код (30 сек тутам солигдоно), "ирээгүй" тэмдэглэх, ажилтнаа үнэлэх, захиалгын хүсэлт илгээх, нэхэмжлэх |
| `admin.html` | STM админ | Хяналт, тайлан, төсөл/захиалга (хуулийн шалгалттай), оноогоор автомат сонголт, ажилчид, захиалагчид, сургалт засварлагч, мессеж, гэрээ/нэхэмжлэх, цалин олголт, тохиргоо |

| Файл | Тайлбар |
|---|---|
| `app.js`, `app.css` | Гурван хуудасны нийтлэг апп |
| `logic.js` | Оноо, шаардлага, хуулийн шалгалт, цалин, нэхэмжлэхийн тооцоо. **`apps-script/Logic.gs`-тэй ЯГ ИЖИЛ** |
| `config.js` | Apps Script-ийн URL |
| `qrcode.js` | QR зурах сан (MIT, Kazuhiko Arase) |
| `apps-script/Code.gs`, `apps-script/Logic.gs` | Backend |
| `src/`, `build.sh` | `app.js`-ийн эх хэсгүүд. Засвар хийвэл `./build.sh` ажиллуулна |

---

## 1. Apps Script шинэчлэх (одоо байгаа төсөлд)

1. Одоогийн Apps Script төслөө нээнэ (script.google.com).
2. `Code.gs`-ийн агуулгыг бүгдийг устгаад `apps-script/Code.gs`-ийг хуулж тавина. `SPREADSHEET_ID` хэвээр байгаа эсэхийг шалгана.
3. Зүүн талын **Files → + → Script** дарж `Logic` нэртэй файл үүсгээд `apps-script/Logic.gs`-ийн агуулгыг хуулж тавина. **Save** (💾).
4. Дээд хэсгийн функцийн жагсаалтаас `setup`-ийг сонгоод **Run** дарна. Шинэ хуудсууд үүснэ: Оюутнууд, Төслүүд, Өдрүүд, Ээлжийн бүртгэл, Сургалт, Мессеж, Яаралтай, Захиалгын хүсэлт. «Байгууллагууд» хуудсанд «Оюутанд харагдах нэр», «Ажилтны тоо» багана нэмэгдэнэ.
5. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. URL өөрчлөгдөхгүй тул `config.js`-д хүрэх шаардлагагүй.

Script properties (Project Settings → Script properties):
- `<админы нэр>` = нууц үг (хуучнаараа ажиллана).
- `SITE_URL` (сонголттой) — сайтын хаяг, жишээ нь `https://binzo9.github.io/tsagiin-ajil/`. Хоосон бол энэ хаяг автоматаар орно. Имэйл дэх линкүүдэд ашиглана.
- `STM`, `TOKEN_SECRET`, `CONFIG` — систем өөрөө үүсгэнэ, бүү устга.

> Шинээр эхлүүлж байгаа бол: [sheets.new](https://sheets.new) → Extensions → Apps Script → дээрх алхмууд → **Deploy → New deployment → Web app**, Execute as: **Me**, Who has access: **Anyone** → URL-ийг `config.js`-д тавина.

## 2. GitHub Pages дээр байршуулах

Repo-д дараах файлуудыг upload хийнэ (хуучныг нь дарна):
`index.html`, `company.html`, `admin.html`, `post.html`, `app.js`, `app.css`, `logic.js`, `config.js`, `qrcode.js`, `sw.js`, `manifest.webmanifest`, `manifest-student.webmanifest`, `icons/` хавтас (шинэ `logo.png`-тэй).
Хуучин `style.css`, `common.js` хэрэггүй болсон тул устгаж болно.

## 3. Анх эхлэхэд

1. **admin.html** → нэвтрэнэ.
2. **Захиалагчид → + Захиалагч нэмэх**: нэр, «Оюутанд харагдах нэр», **ажилтны тоо** (хуулийн 30%-ийн дүрэмд заавал), имэйл. Захиалагчид нууц үг тохируулах заавар имэйлээр очно. Хуучин бүртгэлтэй байгууллагууд шууд нэвтэрч болно — тэдний ажилтны тоо, харагдах нэрийг «Засах»-аар бөглөнө.
3. **Сургалт, тест**: захиалагч бүрт сургалт (видео линк, алхмууд, асуултууд) үүсгэнэ. Сургалтгүй захиалагчийн ажилд оюутан тестгүйгээр бүртгүүлнэ.
4. **index.html** линкийг (хуучин QR `qr-anket.png` ч ажиллана) оюутнуудад тараана. Оюутан утас + нууц үгээр бүртгүүлнэ.
5. Цагаан хуудастай оюутны хуудсыг үзээд **Ажилчид → Засах**-аас дуусах огноог оруулна. Жолооны үнэмлэхийг мөн адил.

## 4. Ажлын урсгал

1. Захиалагч **company.html → Захиалга хүсэх** (эсвэл албан бичиг ирүүлнэ).
2. Админ **Төсөл, захиалга** → хүсэлт дээр «Захиалга болгох» (эсвэл «+ Захиалга бүртгэх»). Хуулийн шалгалт: доод цалин, 21:00-оос хойш тээвэр, 22:00-оос хойш 18+, ажилтны 30%, 6 сар, 12 цаг.
3. «Гэрээ илгээх» → захиалагчид имэйл → захиалагч company.html-д гэрээг цахимаар зурна → зар оюутнуудад гарна.
4. Оюутан өдрөө сонгож бүртгүүлнэ (сул өдөр/цаг, цагаан хуудас, тест, 18+, долоо хоногт 32 цаг автоматаар шалгагдана).
5. Админ «Нээлттэй бүх өдрийг оноогоор бөглөх» → оюутанд мессеж (+ имэйл) → оюутан 2 цагийн дотор баталгаажуулна. Хугацаа хэтэрвэл Хяналтад анхааруулга гарна.
6. Ажлын өдөр захиалагчийн хариуцагч company.html-ийн QR-ийг харуулна. Оюутан утасныхаа камераар уншуулахад (эсвэл 6 оронтой код) ирц бүртгэгдэнэ. Явахдаа дахин.
7. Захиалагч үнэлнэ, админ «Ажил дууссан» гэж тэмдэглэнэ → **Цалин олголт**-оос шилжүүлсний дараа «Олгосон» дарна → **Гэрээ, нэхэмжлэх**-ээс нэхэмжилж, төлбөр ормогц тэмдэглэнэ.

## 5. Аюулгүй байдал

- Нууц үгийг salt-тай SHA-256 (300 давталт) hash-аар хадгална. 5 буруу оролдлогод 10 минут түгжинэ.
- Оюутан захиалагчийн жинхэнэ нэр, бусдын бүртгэл, тестийн зөв хариулт, баталгаажуулаагүй ажлын хаягийг харахгүй (сервер талд шүүнэ).
- Захиалагч зөвхөн өөрийн төсөл, багийнхаа нэрийг харна (утас, хувийн мэдээлэл харагдахгүй).
- Ирцийн код нь серверийн нууц түлхүүрээр 30 сек тутам үүснэ; оюутан урьдчилан тооцох боломжгүй.
- Sheet-ийн хуваалцах тохиргоог **Restricted** хэвээр үлдээнэ.

## 6. Хязгаарлалт

- Энгийн Gmail өдөрт ~100 имэйл илгээнэ. Тохиргоо → «Сонгогдсон оюутанд имэйлээр мэдэгдэх»-ийг унтрааж хэмнэнэ (апп доторх мессеж үргэлж очно).
- Apps Script хариу 1–3 секунд. Апп 60 секунд тутам өөрөө шинэчлэгдэнэ.
- iPhone-д нүүр дэлгэцэнд суулгасан апп Safari-гаас тусдаа нэвтрэлттэй. QR-ийг камераар уншуулахад Safari нээгдэх тул тэнд нэг удаа нэвтэрнэ, эсвэл 6 оронтой кодыг ашиглана.
- Хурууны хээ, видео эцэс хүртэл үзсэн эсэхийн автомат шалгалт байхгүй (прототипд зөвхөн дүрслэл байсан).
- Хуучин «Бүртгэл», «Зарууд» хуудсууд Sheet-д хэвээр үлдэнэ, шинэ систем тэднийг ашиглахгүй.
- Суутгалын хувь (НДШ, ХХОАТ), гэрээний текстийг нягтлан, хуульчаар шалгуулна. Хөдөлмөрийн хөлсний доод хэмжээ (одоо 792,000₮, 2027-01-01-ээс 1,000,000₮) Тохиргооноос засагдана.

## Код засах

`src/*.js` эсвэл `logic.js`-ийг засаад `./build.sh` ажиллуулна: `app.js` нэгтгэгдэж, `logic.js` → `apps-script/Logic.gs` хуулагдана. Logic.gs-ийг Apps Script-д мөн шинэчилж, шинэ version deploy хийнэ.
